Uni4Read — versão atualizada

Arquivos: feed.html, lidos.html, lendo.html, amigos.html, style.css, script.js e assets/.

Abra feed.html no navegador. Cada página possui seu próprio HTML e o script filtra os livros pelo status: "lido" ou "lendo". Para trocar um livro de status, use o menu ⋮ do cartão e selecione Alterar status. Os livros e amigos são salvos no localStorage deste navegador.

Observação: o armazenamento local é específico do navegador e dispositivo; não é sincronizado com outros usuários.
